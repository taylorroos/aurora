# ADR-0001 — Arquitetura Monorepo

## Status

Aceita

## Contexto

O Projeto Aurora foi concebido como uma plataforma composta por diversos produtos e serviços que compartilharão componentes, documentação e infraestrutura.

## Decisão

O projeto será organizado como um monorepo.

## Consequências

- Compartilhamento facilitado de código.
- Documentação centralizada.
- Crescimento organizado.
- Expansão futura para aplicações web, mobile, APIs e serviços.
